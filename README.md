# PersonWeb - Personal Portfolio

A Vue 3 personal portfolio website built with Vite, Element Plus, and Pinia.

## Features

- **Responsive Design**: Mobile-first layout.
- **Dark Mode**: Toggle between light and dark themes.
- **Internationalization (i18n)**: English and Chinese support.
- **Projects & Blog**: Showcase your work and thoughts.
- **Contact Form**: Easy way to get in touch.

## Tech Stack

- Vue 3 (Composition API)
- Vite
- Pinia (State Management)
- Vue Router
- Element Plus (UI Library)
- Vue I18n

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run development server:

   ```bash
   npm run dev
   ```

3. Build for production:

   ```bash
   npm run build
   ```

## Customization

- **Content**: Update texts in `src/locales/`
- **Projects**: Edit `src/views/ProjectsView.vue` and `HomeView.vue`
- **Blog**: Edit `src/views/BlogView.vue`
